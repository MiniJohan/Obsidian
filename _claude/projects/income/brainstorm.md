## Ideas

### 🟢 Fast to start / High feasibility

#### Freelance Web Development
- Build sites, apps, or tools for clients — local businesses or remote
- Platforms: Upwork, Fiverr, PeoplePerHour, Frilans.nu (SE), Jobbsafari
- Stack fit: ★★★★★
- Time to first money: weeks (dependent on client acquisition)
- Blockers: portfolio visibility, proposal quality, initial reviews
- Notes: Mise and Empty PWA are real, polished demos. VALE shows backend/AI depth. Portfolio is ready.

#### React / Vite / Supabase Starter Templates
- Build opinionated, well-designed starter kits and sell them
- Sell on: Gumroad, Lemon Squeezy, Envato Elements
- Stack fit: ★★★★★
- Time to first money: 1–3 weeks to build and list
- Ceiling: low per sale, but passive if marketed
- Notes: Differentiate on design quality and Supabase integration — most templates are ugly

#### Small Gigs / Bug Fixes
- Codeable, Fiverr, PeoplePerHour micro-tasks
- Low effort per task, fast turnaround, builds reviews
- Good starter strategy to get first money and first feedback

---

### 🟡 Medium feasibility / Some ramp

#### Micro-SaaS
- Small, focused tool solving a real problem — monetised via subscription or one-time fee
- Stack fit: ★★★★ — but needs a real pain point and distribution plan
- Time to first money: weeks to months depending on idea + marketing
- Candidates: AI transcription tool (Whisper), local AI dashboard, niche productivity tool
- Notes: VALE is already adjacent. Risk is distribution, not building.

#### AI Niche Consulting / Setup Help
- Local AI stack is a genuine skill gap for many — help people set it up
- Format: async consulting, Discord communities, forums (Reddit r/LocalLLaMA), direct
- Stack fit: ★★★★
- Notes: Undervalued skill right now. VALE is proof of ability.

#### Open Source + Sponsorship / GitHub Sponsors
- Publish something genuinely useful (VALE stripped, a PWA boilerplate, Supabase helpers)
- Monetise via GitHub Sponsors, Buy Me a Coffee, or Polar.sh
- Long game — not fast money, but builds audience

---

### 🔴 Long ramp / Lower priority now

#### Dev Content (YouTube / Blog)
- Tutorials, walkthroughs, opinion pieces
- High effort, slow feedback loop, algorithm-dependent
- Could complement other streams — not a starting point

#### Courses / Teaching
- Same long ramp as content
- Worth revisiting once reputation is established
