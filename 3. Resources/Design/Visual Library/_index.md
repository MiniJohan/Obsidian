## Workflow

1. Find something worth keeping
2. Open the right category folder
3. Create new note, name it descriptively (e.g. `Linear — Empty State`, `Raycast — Command Palette`)
4. Insert the matching template (`Cmd+T` or copy from `_templates/`)
5. Fill in the fields — especially **What I'm stealing** and **Use case**
6. Attach or link the image

**Naming convention:** `[Source] — [What it shows]`
Examples: `Vercel — Dark table hover`, `Spotify — Now playing bar`, `Abstract — grain texture on black`
